# A Arte da Guerra — Nicolau Maquiavel

Landing page estática responsiva em HTML e CSS, com identidade visual cinematográfica.

## Conteúdo
- `index.html`: página de vendas.
- `assets/capa-principal.webp`: capa principal.
- `assets/capa-alternativa.webp`: capa alternativa.
- `vercel.json`: configuração para hospedagem estática na Vercel.

## Publicação na Vercel
1. Importe este repositório em https://vercel.com/new.
2. Framework Preset: **Other**.
3. Root Directory: `./`.
4. Build Command: deixe vazio.
5. Output Directory: `.`.
6. Clique em Deploy.

## Antes de divulgar
Edite o link `INSIRA_AQUI_SEU_LINK_DE_CHECKOUT_HOTMART` no `index.html` e substitua pelo checkout correto. Não há depoimentos inventados; inclua apenas avaliações reais e autorizadas.

O PDF integral do livro não foi incluído no repositório. Confirme os direitos da edição, tradução e elementos editoriais antes de comercializar ou redistribuir o arquivo.
